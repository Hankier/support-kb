How the count was made

  1. One id, one report. The ticket system exports overlapping pages, so some reports appear twice. uniqueById drops the extra copies.
  2. Place, not tag. Intake picks product from the subject line at night, and that is a guess. placeOf uses the reporter’s tenant, so some reports tagged sched-prod move to tram-3 or rota-6.
  3. Server code, not client noise. E-UI-… and E-NET-… come from the client app. A report is filed under the server code (E-TZ-…, E-SYNC-…) next to them.
  4. One person, one reporter. Letter case and +tag in an email address do not count as a new person.
